# Wedding Invitation — Vue 3 + Vite

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Structure
- `src/components` — invitation sections
- `src/composables` — reusable countdown and scroll logic
- `src/assets/styles` — theme variables, global styles, animations
- `public/images` — final optimized photos
- `public/music` — optional background music
- `public/icons` — favicons and interface icons
